## 发现与修复对照

### 🔴 高危

| # | 问题 | 修复 |
|---|---|---|
| H1 | API 无鉴权：CSRF 三重闸门只防**跨站浏览器请求**，信任模型是"DSH web 只监听 127.0.0.1"。一旦端口被暴露（如 dsh-web-lan-access / 端口转发 / 反向代理），**任何能访问该端口的人获得完整写权限**——`mcpm-add` 的 `stdio.command` 可填任意可执行文件 → **远程任意代码执行** | **可选 token 鉴权（纵深防御的最后一道闸）**：`config.token`（loader 行 override，经 Cordis `apply(ctx, config)` 第二参数注入）或环境变量 `DSH_MCP_MANAGER_TOKEN`；启用后所有写操作（add/edit/remove/set-enabled/restart/export/import/skill-toggle）须带 `x-dsh-token` 头，端口被暴露也无法注入命令；读操作（list/version）保持开放。client 设置页新增"访问令牌"输入（localStorage 记忆）。默认关闭，本地单机无需配置 |

## 审计确认的正面项（未改动）

- **CSRF 三重门**：POST-only + `x-dsh-plugin` 头 + Origin 校验
- **YAML 注入防护**：所有值 `JSON.stringify` 引用（含 env/headers 的 key/value），id 白名单
- **XSS 防护**：client 无 `dangerouslySetInnerHTML`；headers 显示掩码（maskKv）
- **凭证分层**：模型工具不暴露 command/env/headers
- **写锁串行化**：所有 patch 写入经 `withWriteLock`
- **guard 短路顺序**：回归测试锁死（6 例）
- **防御性编程**：外部服务依赖 try/catch 降级；`plugin-version` 读不到 package.json 时降级 'unknown'
